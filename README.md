# PRESEC STAFF 4 BASIC SCHOOL — SBA & Report Card App

Mobile-first PWA based on the supplied SBA workbook and JHS report card.

## App PIN
1060

## Source-derived scoring
Each subject has:
- Class Test 1: 30
- Class Test 2: 30
- Home/Project Work: 20
- Group Work: 20
- Total class score: 100
- Class/SBA contribution: 50%
- Examination contribution: 50%
- Overall: class contribution + exam contribution

Subject grade scale from the workbook/report card: 1 (90–100), 2 (80–89), 3 (70–79), 4 (60–69), 5 (55–59), 6 (50–54), 7 (40–49), 8 (35–39), 9 (0–34).

Class aggregate logic in the supplied workbook: English + Maths + Science + Social + the two smallest grade numbers among Ghanaian Language, Computing, RME, Career Technology, Creative Arts and French. Class position is ranked by grand total.

## Install on Android
1. Host the folder over HTTPS (GitHub Pages, Netlify, Vercel, or a school web server).
2. Open the URL in Chrome on Android.
3. Choose **Add to Home screen / Install app**.
4. The app works offline after first load.

This package is a PWA source package; an Android APK still requires an Android build environment (Android SDK/Gradle) to compile.
